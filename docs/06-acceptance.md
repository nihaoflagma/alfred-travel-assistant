# 6. Сценарии приёмки и трассировка

Это спецификация проверок будущей реализации. Сценарии не являются отчётом о проведённых интеграционных тестах.

| ID | Условия и действие | Ожидаемый результат | Требования |
|---|---|---|---|
| AC-01 | Принят новый статус DELAYED с задержкой 45 минут | Время и версия плана обновлены, сохранены конфликт при его наличии и outbox | FR-01, FR-04 |
| AC-02 | То же событие доставлено повторно | Нет повторного изменения версии или одинакового уведомления | FR-03 |
| AC-03 | После версии 12 пришла версия 11 основного провайдера | Версия 11 только в аудите; актуальное время не изменилось | FR-02, FR-03 |
| AC-04 | CANCELLED получен, приложение офлайн | План отмечает отмену; уведомление сохранено и доступно после подключения | FR-05, FR-09 |
| AC-05 | Подтверждение отправлено с plan_version=7, текущая версия 8 | 409 PLAN_VERSION_CONFLICT, внешней покупки нет | FR-08, FR-09 |
| AC-06 | Для группы из трёх человек найдено два места | Предложение недоступно для подтверждения группы | FR-06 |
| AC-07 | Багаж платный, но доплата известна | Указана полная цена с багажом; нет скрытой доплаты | FR-06 |
| AC-08 | Для одного пассажира visa UNKNOWN | Вариант требует проверки; подтверждение отклонено | FR-06 |
| AC-09 | Пересадка проходит через полночь и разные зоны | Разность считается в UTC, локальные даты и зоны отображаются отдельно | FR-04, FR-06 |
| AC-10 | После запроса покупки наступил таймаут | RECONCILING, проверка результата у поставщика, повторная покупка не запускается вслепую | FR-08 |
| AC-11 | Два подтверждения с одним Idempotency-Key и телом | Возвращается одна и та же операция, один запрос покупки | FR-08 |
| AC-12 | Тот же ключ, но другой alternative_id | 409 IDEMPOTENCY_CONFLICT | FR-08 |
| AC-13 | Истёк expires_at предложения | 410 OFFER_EXPIRED, требуется обновление поиска | FR-06, FR-08 |
| AC-14 | Нет подтверждения доставки push критического изменения | Email после согласованного ожидания, если разрешён; центр уведомлений сохраняет историю | FR-05 |
| AC-15 | Наступил delete_after паспортного документа | Документ и производные копии недоступны; есть обезличенный аудит; бэкап не возвращает документ | FR-10 |
| AC-16 | Чужой пользователь обращается к trip_id | Доступ отклонён; состав поездки и документы не раскрываются | NFR-05 |
| AC-17 | Во время покупки изменился план; поставщик подтвердил билет | Бронь сохранена, операция сверяется с новой версией; параллельные изменения не затёрты | FR-08 |
| AC-18 | Все поставщики статуса недоступны | План доступен с временем последней проверки; ложная отмена не создаётся | FR-02, NFR-03 |
| AC-19 | Два разных ключа одновременно заменяют одну бронь | Одна активная операция; второй запрос получает 409 OPERATION_IN_PROGRESS | FR-08 |
| AC-20 | Следующий рейс через 20 мин после прибытия, требуемая пересадка 60 мин | Выявлен конфликт, вариант не предлагается как достижимый | FR-04, FR-06 |
| AC-21 | Есть 90 минут ожидания, выход из транзитной зоны неизвестен | Городская активность не предлагается как безопасная; рассматриваются варианты внутри зоны | FR-07 |
| AC-22 | В повторной проверке цена выросла | RECONFIRMATION_REQUIRED; новая сумма не списана без подтверждения | FR-08 |
| AC-23 | Разные источники прислали противоречащие статусы | Пометка расхождения и сверка с основным источником; версии провайдеров не смешаны | FR-02, FR-03 |
| AC-24 | GET плана или уведомлений с временно недоступным поиском | Чтение доступно, поиск возвращает контролируемую ошибку/повтор позже | NFR-03 |

## Проверки перед запуском

Нужны контрактные проверки на песочницах поставщиков, проверка OAuth/прав по ролям, нагрузочный тест на согласованном профиле, проверка восстановления из бэкапа с реестром удалений, а также тест часовых поясов и календарных переходов. Согласуются таймауты, квоты, параметры опроса, срок хранения ключей идемпотентности и период сверки неизвестных покупок.

Ни подключений к реальным перевозчикам, ни проведения платежей данный проект не подтверждает.
